# Meleesha Farm Shop

Website for Meleesha Farm Shop: eggs, chicken and groceries, with ordering by WhatsApp.

- `index.html` is the whole site (HTML, CSS and JavaScript in one file).
- `logo/` holds the logo files.

To view it, open `index.html` in a browser. To change items, edit the `ITEMS` list near the bottom of `index.html`.
